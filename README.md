# My Portfolio

Portafolio personal de **Alberto Almaguer** — Frontend Developer especializado en crear experiencias web modernas, accesibles y responsive.

## Sobre mí

Desarrollador frontend con 2 años de experiencia y conocimientos básicos en backend. Me especializo en construir aplicaciones web estéticas, responsive y optimizadas, combinando buenas prácticas de maquetación con herramientas modernas para potenciar el rendimiento y la experiencia de usuario.

## Tech Stack

- **HTML5 & CSS3** — Maquetación semántica y estilos modernos
- **JavaScript (ES6+)** — Lógica interactiva vanilla
- **Diseño Responsive** — Adaptable a cualquier dispositivo
- **Dark Mode** — Toggle de tema claro/oscuro
- **Animaciones CSS** — Transiciones y efectos suaves
- **GitHub Pages** — Despliegue gratuito y continuo

## Características del portafolio

- **Diseño Responsive** — Se adapta a mobile, tablet y desktop
- **Modo Oscuro** — Toggle para cambiar entre tema claro y oscuro
- **Animaciones** — Barras de progreso animadas y transiciones suaves
- **Performance** — CSS y JS vanilla para máxima velocidad de carga
- **SEO básico** — Meta tags y Open Graph para redes sociales
